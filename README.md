# Privacy Policy - Aurea Extension

**Last updated:** October 2026

This Privacy Policy explains how **Aurea Extension** ("we", "our", or "us") collects, uses, stores, and protects user data when you use our Chrome extension.

---

### 1. Data Collection & Information We Process
To provide core functionality, license verification, and Discord automation features, Aurea Extension processes the following information:

* **Authentication Credentials:** Discord authentication tokens extracted locally to authorize Quest and HypeSquad actions via Discord APIs.
* **Account Identifiers:** Basic Discord account information, including Username, User ID, and Discriminator.
* **Network & Location Data:** IP address, approximate geographical location (City, Region, Country, ISP), and precise GPS coordinates (if explicitly requested/provided by the user).
* **Device Telemetry:** Device User-Agent strings, hardware identifiers (HWID), and basic system configuration.
* **Local Storage Data:** Extension settings, selected preferences, and active license keys stored locally using `chrome.storage.local` and `localStorage`.

---

### 2. How We Use Your Data
The collected data is strictly used for the following internal purposes:
* Authenticating valid extension user licenses and preventing unauthorized license sharing.
* Automating Discord Quests and HypeSquad badge assignments on behalf of the user.
* Logging system performance, debugging telemetry, and displaying status updates inside the administrative control panel.

---

### 3. Data Sharing & Third-Party Disclosure
* **No Sale of Data:** We do not sell, rent, trade, or transfer any user data or credentials to third parties under any circumstances.
* **External Services:** Necessary requests may be processed through official Discord API endpoints (`discord.com`), geolocation services (`ip-api.com`), and OpenStreetMap (`nominatim.openstreetmap.org`) strictly to resolve geographical and account features requested by the user.

---

### 4. Data Security & Storage
* All local settings and keys are secured using standard Chrome extension storage APIs.
* Remote telemetry data processed for license verification is accessible only by authorized administrators.

---

### 5. Compliance with Chrome Web Store Policies
Aurea Extension complies with the Chrome Web Store User Data Policy, including the Limited Use requirements. We request only the minimum necessary permissions required for the extension's functional operations.
